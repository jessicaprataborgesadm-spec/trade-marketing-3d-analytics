# 📊 Trade Marketing 3D Analytics

Um simulador preditivo em 3D construído para transformar a análise de gôndola e a tomada de decisão no varejo.

## 🎯 O Problema
A análise de Trade Marketing tradicional depende de planilhas estáticas que dificultam a visualização do impacto real de rupturas, reposicionamento e elasticidade de preço no ponto de venda.

## 💡 A Solução
Desenvolvi uma aplicação interativa que une análise de dados e renderização 3D para simular cenários (A/B) em tempo real, calculando o **Lucro Incremental** com base em descontos e variações climáticas.

## 🛠️ Hard Skills Aplicadas
* **Python & Pandas:** Tratamento e integração de bases de dados (CSV).
* **Streamlit:** Estruturação executiva da aplicação web.
* **Three.js (WebGL):** Renderização 3D interativa (Raycasting) direto no navegador.
* **Capacidade Analítica:** Tradução de dados puros em lógicas de negócio reais, como *Fair Share Index* e projeção de lucro.

## 🚀 Como executar o projeto localmente
1. Clone este repositório.
2. Instale as dependências: `pip install -r requirements.txt`
3. Rode a aplicação: `streamlit run app.py`
